These links become available after the first successful release workflow.

The ZIP contains `nd_report_studio` and `nd_sale_flow`. Back up the database,
filestore, and existing module folders before updating. Verify the ZIP checksum,
deploy both modules, and run an Odoo module upgrade before restarting normal
service.

Release assets are published by the NovelStudio source repository's
**Release Odoo Modules ZIP** GitHub Action.
